ROS 2 TurtleBot3 Assignment

Project Overview

This project is part of the Robotics Software Intern assignment at Antropi Robotics. The objective is to set up a TurtleBot3 robot in Gazebo using ROS 2 Jazzy and explore autonomous navigation with the Nav2 stack.

Objectives

- Set up the TurtleBot3 simulation environment.
- Explore ROS 2 Jazzy and Gazebo.
- Configure and investigate Nav2 autonomous navigation.
- Understand obstacle avoidance and robot navigation workflows.

Technologies Used

- ROS 2 Jazzy
- Ubuntu 24.04
- Gazebo
- Nav2
- TurtleBot3
- RViz2
